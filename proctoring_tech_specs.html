Feature Category Technology / Library Model / Method Purpose & Functionality
Face Tracking & Liveness MediaPipe Face Mesh face_mesh Detects 468 facial landmarks to track head pose (looking away), eye blink (liveness), mouth opening (talking), and face distance.
Object Detection TensorFlow.js + Coco-SSD coco-ssd (MobileNet) Detects prohibited objects like "cell phone", "book", or "laptop" in the video feed in real-time.
Impersonation Check face-api.js tinyFaceDetector, faceRecognitionNet Captures a reference face at start and compares it periodically (Euclidean distance) to ensure the same student is sitting.
Emotion Detection face-api.js faceExpressionNet Analyzes facial expressions to detect high levels of "fear" or "stress" (potential indicators of cheating behavior).
Voice & Noise Detection Web Audio API AudioContext, AnalyserNode Analyzes audio frequency spectrum in real-time to detect high volume levels (talking or background noise) exceeding thresholds.
Speech Recognition Web Speech API SpeechRecognition Converts speech to text to flag suspicious keywords like "Hey Google", "Alexa", "What is", "Help".
System Integrity WebGL API WEBGL_debug_renderer_info Inspects the GPU renderer string to detect if the exam is running inside a Virtual Machine (VM) (e.g., VMware, VirtualBox).
Anti-Tamper JavaScript Debugger Trap debugger; statement timing Detects if the user opens Browser Developer Tools (F12) by measuring execution pauses caused by the debugger statement.
Environment Check Canvas API Pixel Manipulation Analyzes video frame brightness (pixel intensity) to ensure the room environment is not too dark for effective proctoring.
Focus Tracking Page Visibility API document.visibilityState Detects whenever the user switches tabs, minimizes the browser window, or loses focus on the exam page.
